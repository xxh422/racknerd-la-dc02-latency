## 各机房到国内延迟的真实数据

 DC-02 的延迟白天稳定在 160–180ms，电信联通用户会更低一些，综合各来源口径大致落在 150–190ms 区间。圣何塞平均约 165ms，有时比 DC-02 还略低，移动用户在圣何塞表现更好的情况不少见。第三方实测（idc1680 对 DC02 一台 1 核 1.2G 机器的回程测试）数据大致是：北京联通 168–186ms、北京电信 174–186ms、北京移动 179–222ms、上海电信 162–191ms、上海联通 197–220ms。

晚高峰是分水岭。国内 9–11 点这个时段，DC-02 的电信用户丢包会上升，实测有时达到 10–20%，移动和联通相对干净，多数测评显示丢包 0%。这是普通直连线路的正常现象，不是 DC-02 特有的毛病。测速那台机器硬盘 I/O 平均读写 813.7 MB/s，国外基本能跑满 1Gbps 带宽，国内打个折扣属正常。

IP 质量也值得单独说：DC-02 的美国原生 IP 解锁 YouTube Premium 美区、Disney+、Amazon Prime Video 美区没问题，Netflix 只能看自制剧，ChatGPT 无需 WARP 可以直接访问，Google 验证码很少弹。LA DC02 的测试 IPv4 是 `204.13.154.3`，圣何塞是 `192.210.207.88`，下单前拿这些 IP 在自己常用的网络环境 ping 一遍，尤其是晚高峰 20:00–23:00，比看任何测评都准。
